# Misión espacial

- **Emoji y mascota:** 🚀, el zorro astronauta.
- **Tono de los mensajes:** de misión: "¡Cuenta atrás!", "¡Despegamos!".
- **Etapas que trabaja y orden:** G3 (`space-01` a `space-04`): números, plurales y "They are…". Siguiente natural: G5 con preguntas ("Is it a rocket?").
- **Banco de vocabulario:** `w_one…w_six, w_star, w_moon, w_sun, w_rocket, w_planet, w_alien`. Previsto: números 7-10.
- **Mezcla de ejercicios típica:** `pick-image` y `match` para números y objetos, `fill-blank` singular/plural, `order-words` con cantidades.
- **Lección jefe:** `space-04` "Boss: Space mission", repasa G1-G3.
- **Logros asociados:** `space-explorer`.
- **Ideas de contexto para frases:** contar estrellas, encontrar aliens, preparar un cohete.
