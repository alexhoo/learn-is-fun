# Arcoíris

- **Emoji y mascota:** 🌈, el zorro de la app.
- **Tono de los mensajes:** alegre y colorido, con muchas imágenes.
- **Etapas que trabaja y orden:** G0 colores, luego G2 (`colors-03`, `colors-04`). Siguiente natural: G4 con colores y gustos ("I like red").
- **Banco de vocabulario:** `w_red, w_blue, w_green, w_yellow, w_orange, w_purple` y los animales de la granja para las frases. Previsto: pink, black, white.
- **Mezcla de ejercicios típica:** `pick-image` de color, `fill-blank` con el color o el tamaño, `order-words` con "The … is …".
- **Lección jefe:** pendiente. Repasaría G1-G2 con colores y tamaños.
- **Logros asociados:** `rainbow-explorer`.
- **Ideas de contexto para frases:** describir dibujos, pintar animales, comparar tamaños.
